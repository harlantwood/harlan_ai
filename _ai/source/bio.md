### Trust Graph

Trust Graph, his open source passion project, is an interchange format for reputation
information. Neutral and unopinionated, it is a base layer which can absorb existing reputation

enable systems such as peer to peer "credit ratings" to help bootstrap the unbanked and

credentials; decentralized academic peer review; and many more.

### Use these

**"Programming since 1984."** Stronger and more specific than "20+ years." Both are true — 1984
